# XPlay Web Tools Artwork

Logo + feature art for the XPlay Web Tools listings (1000 tools).

- Each tool has its own folder: `<slug>/logo.png` (512x512) and `<slug>/feature.png` (1024x500).
- Art is drawn per tool from its own name + hub-category colour (see `~/workspace/xplay/web-tools/make_web_tools_art.py`) — never logo==feature, no screenshots, no AI images, no copied art.
- Served raw: `https://raw.githubusercontent.com/SaqGameDev/xplay-web-tools-artwork/main/<slug>/logo.png`
